# V2 muudatused — 2026-09-10

## Loogikamuudatused

- Professionaalsemaid / enterprise-klassi droone ei välistata enam absoluutse filtriga.
- Professionaalsemad mudelid kuvatakse, kui kasutaja:
  - valib öövaatluse,
  - valib termokaamera/soojalekete tuvastamise,
  - valib kinnistu jälgimise või kaardistamise,
  - valib otsingu oma maa-alal,
  - või märgib käsitsi „Luba ka professionaalsemad / enterprise-klassi droonid”.
- Öövaatlust ei samastata enam automaatselt termokaameraga.
- Öö-/hämaras vaatlusvõime sobib nüüd kolmest harust:
  - low-light / Night Mode EO,
  - N/starlight kaamera,
  - thermal.

## Uued andmeväljad droonikataloogis

- `has_night_vision`
- `night_vision_type`
- `night_vision_summary`

## Lisatud või täpsustatud mudelid

- DJI Mavic 3E EU-C1 Worry-Free Basic Combo
- DJI Mavic 3 Pro Fly More Combo DJI RC
- Autel EVO Max 4N V2 Standard Bundle
- DJI Mavic 3T, Matrice 4T ja Autel thermal-mudelid said öövaatluse tunnused.

- „Öö-/hämaras vaatlusvõime on kohustuslik”
- „Luba ka professionaalsemad / enterprise-klassi droonid”
